# contest-prep

Заготовки для контеста Т-Банка: быстрый ввод-вывод и проверенные реализации алгоритмов,
которые реально встречались на их вступительном экзамене.

Каждая структура покрыта тестами — в том числе на краевые случаи, которые
обычно и валят решение: переполнение, длинная цепочка вместо StackOverflow,
пустой и некорректный ввод.

```bash
mvn test    # 45 тестов
```

## Что внутри

| Класс | Зачем | Где пригодится |
|---|---|---|
| `io/FastScanner` | Чтение чисел блоками по 64 КБ | N ≥ 10⁵, иначе Scanner съест лимит времени |
| `algo/DisjointSetUnion` | Связность при добавлении рёбер | «когда граф станет одним куском», Краскал |
| `algo/BinarySearch` | Бинарный поиск по ответу | «минимальное X, при котором успеем/хватит» |
| `algo/ExpressionEvaluator` | Разбор `+ - * ( )` рекурсивным спуском | задача-калькулятор с их экзамена |
| `algo/MinFreeNumber` | Наименьший свободный номер с возвратом | «полки», «столики», пул идентификаторов |
| `algo/Graphs` | BFS и DFS без рекурсии | кратчайшие пути, компоненты связности |

`solutions/Main.java` — шаблон, который копируется в окно ответа целиком.

## Правила их контеста, на которых сыпятся

- Класс называется `Main`, всё в одном файле вместе с импортами.
- Ввод только из stdin, вывод только в stdout. **Никаких «Введите N:»** — это попадёт в ответ и завалит тест.
- Только стандартная библиотека.
- Баллы частичные: 0–100 за задачу по пройденным тестам. Нерешённую до конца задачу
  всё равно имеет смысл сдать.
- **Во время экзамена виден вердикт только по первому тесту.** Остальные прогонят после.
  «ОК» ≠ 100 баллов, поэтому краевые случаи проверяйте локально сами.
- `out.flush()` в конце обязателен.
